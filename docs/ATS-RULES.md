# ATS Resume Compliance Rules

Every resume generated by Alexecutive Career Ops follows these rules to maximize ATS pass-through rates.

## Layout

- Single column ONLY — no sidebars, no two-column designs
- No text boxes, shapes, or floating elements
- No headers or footers (ATS often can't read them)
- Name and contact info must be in the document body, not a Word header
- Maximum 2 pages (1 page for < 5 years of experience)

## Formatting

- Standard fonts only: Arial, Calibri, Cambria, Georgia, Times New Roman
- Body text: 10–12pt | Name: 14–16pt | Section headers: 12–14pt bold
- Margins: 0.5 to 1 inch on all sides
- Use bold sparingly, italic sparingly, no underline (confused with hyperlinks)
- Consistent date format throughout: "Jan 2020 – Present" or "January 2020 – Present"

## Section Headers (exact wording required)

Use these exact headers — ATS parsers look for standard labels:

| Use This | Not This |
|---|---|
| `Experience` | "Professional Journey", "Career History", "Work History" |
| `Education` | "Academic Background", "Schooling" |
| `Skills` | "Competencies", "Toolkit", "Core Strengths" |
| `Certifications` | "Credentials", "Licenses & Certs" |
| `Summary` | "Profile", "About Me", "Objective" |

## Content Rules

- All text must be real, selectable text — no text embedded in images
- No tables nested inside tables (simple single-row skill tables are OK)
- No images, logos, icons, or decorative graphics
- Bullet points: use standard bullet (•) or hyphen (-), not fancy symbols (★, ◆)
- LinkedIn URL as plain text, not hyperlink-only
- Include both acronym and full form: "Search Engine Optimization (SEO)"

## Keyword Strategy

- **Mirror exact phrases** from the job description — don't paraphrase
  - JD says "project management" → your resume says "project management" (not "PM" or "programme management")
- Place high-priority keywords in the **first third** of the resume (Summary + first role)
- Skills section: list JD-matching keywords first, then additional skills
- Each bullet should contain at least one relevant keyword where natural
- Don't keyword-stuff — one mention per section is enough for most ATS systems

## File Output

- Generated as clean HTML that prints to PDF via browser (Cmd+P / Ctrl+P)
- `@media print` CSS for clean print output
- `@page` rules for Letter (US) or A4 (international) sizing
- No JavaScript in the HTML
- Filename: `{FirstName}-{LastName}-{Company}-{Role}.html`

## Common ATS Fails to Avoid

| ❌ Avoid | ✅ Do Instead |
|---|---|
| Text in image (e.g., scanned resume) | Use a text-based document |
| Multi-column layout | Single column only |
| "Creative" resume templates from Canva | Plain structured HTML/DOCX |
| Tables for job history layout | Paragraph + bullet structure |
| Custom section headers | Standard headers (see above) |
| Inconsistent date formats | Pick one format and stick to it |
| Abbreviations without expansion | "Project Management Professional (PMP)" |
| Hyperlinks with no visible URL text | Write out full URL as text |
