# Mode: Compare

Triggered by `/opus compare` or "compare these offers" / "help me decide between these roles".

## Steps

1. **Identify roles** — ask the user which roles to compare (2–4 max), pull from existing evaluation reports
2. **Build comparison matrix** across:

   | Dimension | Role A | Role B | Role C |
   |---|---|---|---|
   | Overall Score | | | |
   | Compensation | | | |
   | Role Fit | | | |
   | Growth Potential | | | |
   | Company Stability | | | |
   | Remote/Location | | | |
   | Team/Culture | | | |
   | Career Trajectory | | | |

3. **Highlight trade-offs**:
   - Where Role A beats B/C, and vice versa
   - Which deal-breakers (from profile) are triggered by each
   - Compensation delta between offers

4. **Give a recommendation**:
   - Lead with the highest-scoring option
   - Explain in 2–3 sentences why
   - Note the biggest downside of the recommendation

5. **Negotiation leverage**:
   - If multiple offers: explain how to use competing offers to negotiate
   - Suggest specific negotiation angles per offer
